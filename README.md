# Visponsa privacy website

Static GitHub Pages files for Cybapalace. Privacy contact: chiakwak@outlook.com.

## Publish
1. Sign into GitHub as rinokings.
2. Create a public repository named visponsa (or use that repository if it already exists).
3. Extract the supplied ZIP. Upload the CONTENTS of visponsa-pages, not its enclosing folder, to the repository root and commit to main.
4. Open repository Settings > Pages. Under Build and deployment select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the deployment to finish. Check https://rinokings.github.io/visponsa/privacy/ in a private browser window.

The URL is expected, not already live. If the repository has a different name, replace visponsa in the URL. Never overwrite existing project files without reviewing them.
